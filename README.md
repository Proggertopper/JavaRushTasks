# JavaRush Task Solutions

> A personal learning archive of JavaRush exercises and small Java experiments.

This repository documents my Java Core practice while learning with JavaRush.It contains **345 `Solution.java` files** with completed exercises, together with several IntelliJ IDEA projects used to explore Java features in more depth.

This is intentionally a learning repository, not a single production application. Code style and project structure may vary between tasks because each exercise focuses on a specific language feature or problem.

## What I Practised

- Object-oriented programming: classes, encapsulation, inheritance, polymorphism, and interfaces
- Generics, annotations, and reflection basics
- Exceptions, collections, files, and console input/output
- Threads and basic synchronization
- Java syntax, algorithms, and problem-solving through many small tasks
- Small Java games and independent IntelliJ IDEA experiments

## How to Explore the Code

Most JavaRush solutions were created to run in the JavaRush learning environment. To inspect them:

1. Open a task folder and read its `Solution.java` file.
2. Open `javarush-project` in IntelliJ IDEA with the JavaRush plugin/environment configured.

There is no single root build command because this repository contains many independent exercises rather than one application.
